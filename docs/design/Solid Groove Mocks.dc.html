  • Regions are separated by tint and elevation, never borders — flatter, calmer, fewer lines.
  • Five neutral surfaces only; each step up in lightness reads as one step closer to the user.

6cVertical fill-slider — the one continuous control
{{ dsSlidersEl }}
  • Label above, live value below — same style, same place on every slider, always.
  • Thumbless fill track: the filled portion is the value. Drag up/down maps directly to the fill — no learned rotary gesture.
  • The accent fill marks the parameter you're touching; resting sliders use the muted accent.
  • Fixed 48px width (fits an 8-char label) with uniform gaps — sliders only sequence horizontally, never stack.
  • One component everywhere — instruments, effects, mixer — so a slider always reads and behaves the same.
